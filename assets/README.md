# Produktbilleder

GitHub Pages kan vise billeder, der ligger i repoet. Produktkortene forsøger først at vise disse filer:

- `assets/armbaand.jpg`
- `assets/halskaeder.jpg`
- `assets/ringe.jpg`
- `assets/oreringe.jpg`

Upload dine egne billeder med præcis de filnavne, så skifter hjemmesiden automatisk til dem.

Indtil JPG-filerne findes, bruger siden disse fallback-billeder fra designreferencen:

- `assets/armbaand.svg`
- `assets/halskaeder.svg`
- `assets/ringe.svg`
- `assets/oreringe.svg`

Anbefalet format: JPG, gerne kvadratisk eller 5:4, mindst 900 px bredt.
